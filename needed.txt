# 7) Relationship Score System

النقاط تتحسب تلقائيًا.

## Actions & Points

| Action          | User Points | Relationship Points |
| --------------- | ----------: | ------------------: |
| Add memory      |         +10 |                  +5 |
| React to memory |          +3 |                  +5 |
| Add event       |          +8 |                  +5 |
| Complete event  |         +10 |                 +15 |
| Send note       |          +5 |                  +3 |

## Important

* النقاط تتحسب من triggers في Supabase.
* React مايزودش score يدويًا.
* كل activity لها score log.
* نفس reaction مايتحسبش مرتين.
